公募基金数据API

这是一个基于GitHub Pages和GitHub Actions构建的免费公募基金数据API，数据来源于东方财富网，每日自动更新。

注意： 本API仅供学习和研究使用，数据仅供参考，投资决策请以官方数据为准。

API端点

GET /funds_simple.json

精简版基金列表，包含基金代码、名称和类型，适合搜索功能。

文件大小：约1.5MB

GET /funds_full.json.gz

完整版基金数据，包含基金代码、名称、类型、最新净值、日增长率、成立日期、基金经理、基金规模等详细信息。

文件大小：约2MB（压缩后）

注意： 此文件是gzip压缩格式，前端需要正确处理解压。

GET /fund_ranks.json

各类基金收益率排名，包含股票型、混合型、债券型、指数型、QDII、FOF等类型，以及近1周、1月、3月、6月、1年、3年、5年等时间段的前50名。

文件大小：约500KB

使用示例

JavaScript获取精简版基金列表

fetch('https://你的用户名.github.io/fund-data-api/funds_simple.json')
  .then(response => response.json())
  .then(data => {
    console.log(`更新时间: ${data.update_time}`);
    console.log(`基金总数: ${data.total}`);
    console.log('前10只基金:', data.funds.slice(0, 10));
  });

JavaScript获取并解压完整版数据

fetch('https://你的用户名.github.io/fund-data-api/funds_full.json.gz')
  .then(response => response.arrayBuffer())
  .then(buffer => {
    return new Response(new Blob([buffer], {type: 'application/gzip'}))
      .body.pipeThrough(new DecompressionStream('gzip'));
  })
  .then(stream => new Response(stream).json())
  .then(data => {
    console.log(`更新时间: ${data.update_time}`);
    console.log(`基金总数: ${data.total_funds}`);
    console.log('基金排名:', data.ranks);
  });

数据更新

数据每天北京时间18:30自动更新一次，你也可以在GitHub仓库的Actions页面手动触发更新。
